04

Active-Active SQL Testing

Langkah 1: Login ke SQL Shell di terminal terlebih dahulu.

cockroach sql --insecure --host=localhost
Write Data via Node 1 Pending
Paste setelah Login di Node 1
CREATE TABLE IF NOT EXISTS cluster_test (id UUID PRIMARY KEY DEFAULT gen_random_uuid(), val TEXT);
INSERT INTO cluster_test (val) VALUES ('Data from Node 1');
Expected Result
INSERT 1
Read/Update Data via Node 2 Pending
Paste setelah Login di Node 2
SELECT * FROM cluster_test;
INSERT INTO cluster_test (val) VALUES ('Data from Node 2');
Expected Result
Menampilkan data Node 1 & INSERT data baru sukses
Ini membuktikan data yang di-write di Node 1 sudah ada di Node 2 secara instant.
05

High Availability & Failover Test

Simulasi Node Down (Node 2) Pending
Stop Service on Node 2
sudo systemctl stop cockroach
Verify on Node 1 Status
cockroach node status --insecure --host=localhost
Status Node 2 harus berubah menjadi 'is_available: false' namun cluster tetap 'Live'.
Write Data During Failover Pending
Execute via HAProxy
cockroach sql --insecure --host=localhost:26257 -e "INSERT INTO cluster_test (val) VALUES ('Written during failover');"
Expected Result
INSERT 1 (Success)
HAProxy otomatis mengalihkan traffic ke Node yang survive (Node 1 atau 3).
Node Recovery & Catch-up Pending
Langkah 1: Restart Node 2
sudo systemctl start cockroach
Langkah 2: Verifikasi Data di Node 2
# Login di Node 2 lalu cek data:
SELECT * FROM cluster_test WHERE val = 'Written during failover';
Node 2 akan otomatis melakukan 'Catching up' (replikasi ulang) data yang ia lewatkan saat mati. Jika data 'Written during failover' muncul, berarti sinkronisasi berhasil.
Final Integrity Check (Full Sync) Pending
Cek Total Rows di Semua Node
SELECT count(*), val FROM cluster_test GROUP BY val;
Expected Result
Total 3 data berbeda muncul di semua node
